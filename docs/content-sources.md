## Localized visual assets

The deployed site serves all visual assets from `dist/assets/`; it does not depend on third-party image hotlinks. The copies were archived on 2026-10-23 from the original SNT Defense Webflow CDN and the official SNT Motiv defense catalog pages. Original URLs remain documented in Git history and in the public source links above so their provenance can be audited.

- Home, page-hero, card, facility, ethics, and K2/K2C1 imagery: original SNT Defense Webflow CDN (`cdn.prod.website-files.com`)
- K13, K2C, K14, and STSM21 product imagery: official SNT Motiv catalog pages (`www.sntmotiv.com`)
- ISO 14001 preview and PDF: official SNT Motiv environmental archive
